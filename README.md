# Azure Cloud Resume Challenge - Personal Website

This repository contains my Azure Cloud Resume Challenge project.

The goal is to build a personal portfolio website that demonstrates hands-on Azure, development, source control, serverless, infrastructure-as-code, and CI/CD skills.

## Current Phase

Phase 1 - Developer basics and local project setup.

## Planned Architecture

The final project will include:

- Static personal website built with HTML, CSS, and JavaScript
- Azure Storage static website hosting
- Custom domain and HTTPS
- JavaScript visitor counter
- Azure Functions HTTP API
- Python backend logic
- Serverless database for visitor count storage
- Infrastructure as Code
- GitHub Actions CI/CD
- Architecture diagram
- Blog post explaining lessons learned

## Project Structure

frontend/   Static website files
backend/    Azure Function API code
infra/      Infrastructure as Code files
notes/      Learning notes, troubleshooting notes, and blog ideas
